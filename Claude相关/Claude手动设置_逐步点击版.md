# Claude 手动设置和检查步骤

按顺序操作即可。下面沿用你此前选过的“洛杉矶时区、网页英语美国优先”；Chrome 菜单可以继续用中文。它们是可选设置，不是 Claude 官方要求，也不能保证免身份验证。

**操作时只改写明的项目。先记下原值，方便以后改回来。**

## 1 修改 Windows 时区

### 按下面顺序点击

1. 按键盘 **Win + I**，打开 Windows 设置。
2. 点击 **时间和语言**。
3. 点击 **日期和时间**。
4. 找到 **自动设置时间**，把开关设为 **开**。
5. 找到 **立即同步**，点击一次。部分版本在“其他设置”里面。
6. 找到 **自动设置时区**，把开关设为 **关**。这样才能手动选择时区。
7. 点击 **时区** 右边的下拉框。
8. 找到并选择 **(UTC-08:00) 太平洋时间（美国和加拿大）**。
9. 如果有 **自动调整夏令时**，把它设为 **开**。
10. 关掉设置窗口。第 4 部分会检查浏览器有没有读到新时区。

**这一步完成后应当是：**

- 自动设置时间：**开**。
- 自动设置时区：**关**。
- 时区：**太平洋时间（美国和加拿大）**。
- 自动调整夏令时：**开**，有该选项时设置。

不用点击“手动设置日期和时间”，也不用手动把时钟拨快或拨慢。洛杉矶夏季是 UTC-7，冬季是 UTC-8；下拉框写 UTC-08:00、检测网站在夏季显示 UTC-07:00，可以同时正确。

**注意：这会改变整台电脑的时区，所有浏览器用户和其他软件都会受到影响。**

### 想改回中国时间

重新进入同一个地方，在“时区”下拉框选 **(UTC+08:00) 北京，重庆，香港特别行政区，乌鲁木齐**。如果原来用自动设置时区，也可以按实际需要恢复。

## 2 选对 Chrome 用户

1. 打开 Chrome。
2. 点击右上角的 **头像**。
3. 看清当前的 **用户名称和邮箱**。
4. 如果不是你准备用来登录 Claude 的那个用户，点击头像菜单里的目标用户，切换过去。
5. 后面的 Chrome 设置和检测网站，都在这个用户的窗口里操作。

你之前的目标窗口叫“工作／chao”，另一个叫“超”。换电脑后名字可以不同，重点是选对你自己的用户和账号。

## 3 把网页首选语言设为英语美国

### 按下面顺序点击

1. 在刚才选好的 Chrome 窗口里，点击右上角 **三个点**。
2. 点击 **设置／Settings**。
3. 点击左边的 **语言／Languages**。
4. 找到 **首选语言／Preferred languages**。
5. 点击 **添加语言／Add languages**。
6. 在搜索框输入 **英语**。如果界面是英文，输入 **English**。
7. 勾选 **英语（美国）／English (United States)**。
8. 点击 **添加／Add**。
9. 回到语言列表，点击 **英语（美国）右边的三个点**。
10. 点击 **移到顶部／Move to the top**。部分版本叫“上移”，点到第一位即可。

如果列表里已经有“英语（美国）”，直接从第 9 步开始。

### 做完后看这里

语言列表第一项应当是 **英语（美国）**。中文可以留在下面，不用删除。

**不要顺手勾选“以这种语言显示 Google Chrome”。** 那个改的是浏览器菜单，不是网页语言，而且可能让同一套 Chrome 的其他用户菜单一起变成英文。

### 如果想把英文菜单改回中文

只有你需要恢复中文菜单时才做下面几步：

1. 仍在 **Settings → Languages** 页面。
2. 如果没有中文，点击 **Add languages**，添加 **Chinese (Simplified)／中文（简体）**。
3. 点击中文右边的 **三个点**。
4. 勾选 **Display Google Chrome in this language／以这种语言显示 Google Chrome**。
5. 保存所有 Chrome 窗口里正在做的事情。
6. 点击 **Relaunch／重新启动**。

菜单改回中文后，重新确认目标用户的“网页首选语言”仍然是你想要的顺序。

## 4 用网站检查时区和语言有没有生效

### 打开检测网站

1. 在目标 Chrome 窗口按 **Ctrl + L**，选中地址栏。
2. 粘贴这个网址：<https://browserleaks.com/javascript>。
3. 按 **回车**，等页面加载出数据。

### 检查时区

4. 按 **Ctrl + F**，打开页面查找。
5. 输入 **timeZone**。
6. 按 **Esc**，关闭查找框，看页面定位到的那一行。
7. 看 `timeZone` 右边的值。

如果第 1 部分选的是洛杉矶，这里通常应显示：

`America/Los_Angeles`

如果仍然显示 `Asia/Shanghai`：

1. 先按 **Ctrl + R** 刷新网页。
2. 仍然没变，就回 Windows 的“日期和时间”，确认第 1 部分第 8 步确实选中了太平洋时间。
3. 如果你装过“修改时区”的扩展，查看它有没有覆盖系统时区；先记录，不要再叠加安装另一个扩展。

### 检查网页语言

8. 再按 **Ctrl + F**。
9. 输入 **languages**。
10. 按 **Esc**，看这一行的语言列表。

如果第 3 部分设置成功，列表前面应当能看到 **en-US**。下面仍有 **zh-CN、zh**，不代表失败。

### 顺便检查 Cookie

11. 按 **Ctrl + F**，输入 **cookieEnabled**。
12. 按 **Esc**，查看值是否为 **true**。

`true` 表示浏览器支持 Cookie。它不保证每个站点权限都正确；如果你能正常登录和使用网站，先不用改其他权限。

## 5 检查浏览器实际用了哪个 IP

### 先看当前出口

1. 先连接你自己准备使用的网络或代理。
2. 回到目标 Chrome 窗口。
3. 按 **Ctrl + L**。
4. 输入 <https://ping0.cc/>，按回车。
5. 等待结果出来。默认页面会查询当前访问它的出口，不需要先输入别人的 IP。
6. 找到 **IP 地址**，记下来。
7. 找到 **IP 位置**，看国家和城市。
8. 找到 **ASN／ISP**，记下运营商或网络名称。

**怎么看：**

- 你预期走美国出口，就核对页面显示的国家是否为美国。
- 如果买的是固定出口，可以把页面 IP 与供应商后台给你的出口 IP 核对。
- 换电脑后不要照抄旧电脑以前的 IP；要看新电脑当前检测出来的值。

### 再用另一个网站核对

9. 新开一个标签页，打开 <https://ip.net.coffee/claude/>。
10. 等页面自动加载结果，不需要先找“开始检测”按钮。
11. 看页面标为 **Claude AI 出口 IP** 的项目，记录地址。
12. 向下滚动，找到 **用户设备信息**，查看 **时区、语言**。

如果页面一直没有数据，按 **Ctrl + R** 刷新一次。两家网站的城市或“住宅／Hosting”标签可能不同，不能只凭标签断定线路有问题。

**这一步检查的是浏览器。不能因为浏览器显示美国，就认定 Claude 桌面 App 一定也走同一个出口。** 桌面 App 的连接方式要在你使用的代理软件中另外核对。

## 6 检查 DNS

1. 仍然在目标 Chrome 窗口中操作。
2. 按 **Ctrl + L**。
3. 输入 <https://ip.net.coffee/dns/>，按回车。
4. 找到并点击 **快速测试**。
5. 等测试结束。
6. 看下方表格里的 **DNS 解析器 IP、归属地、服务商、状态**。
7. 把结果截图或记下来。

**怎么看：**

- 能生成结果，说明完成了这一次检测。
- DNS 服务器的城市不必和你的出口城市完全一样。
- 出现自己不认识的运营商，先记录，再核对正在使用的网络软件；这不等于已经确定会影响 Claude 账号。

这里先检查即可。不要仅为了“变绿”就同时关闭安全 DNS、IPv6，或随便填写网上找来的 DNS 地址。

## 7 检查 WebRTC 有没有出现另一个公网出口

1. 打开 <https://ip.net.coffee/webrtc/>。
2. 点击 **开始检测**。
3. 等待测试完成。
4. 看结果表格里的 **IP 地址、类型、归属地、状态**。
5. 将这里显示的公网 IP，与第 5 部分记下的出口 IP 比较。

**怎么看：**

- 如果只看到你预期的出口，说明本次没有观察到额外的公网出口。
- 如果没有返回地址，也可能是 WebRTC 或 UDP 请求被阻止，不能据此保证所有网络都没问题。
- 如果出现另一个公网 IP，先截图，核对它属于哪条线路；多个出口也可能来自分流规则。
- `192.168.x.x`、`10.x.x.x` 或以 `.local` 结尾的地址，本身不是你的公网出口。

如果这个网站打不开，可以用备用网站 <https://browserleaks.com/webrtc>。页面会自动检测，查看 **Public IP Address**；不要把 **Local IP Address** 当成公网地址。

不需要为了做这一步安装陌生的“防泄漏”扩展。

## 8 检查 Chrome 的基础设置

### 更新 Chrome

1. 点击 Chrome 右上角 **三个点**。
2. 点击 **帮助／Help**。
3. 点击 **关于 Google Chrome／About Google Chrome**。
4. 等它自动检查更新。
5. 如果提示重新启动，先保存工作，再点击 **重新启动／Relaunch**。

### 查看扩展

1. 点击右上角 **三个点**。
2. 点击 **扩展程序／Extensions**。
3. 点击 **管理扩展程序／Manage extensions**。
4. 看看有没有自己不认识的扩展，特别是会修改代理、时区、语言的扩展。
5. 先记录可疑项目，不要随手关闭你正在使用的网络扩展，避免把网络弄断。

### 只有网页报错时，再检查 JavaScript

1. 点击 **三个点 → 设置**。
2. 点击 **隐私和安全／Privacy and security**。
3. 点击 **网站设置／Site settings**。
4. 点击 **JavaScript**。有的版本需要先展开内容设置。
5. 正常默认选项是 **网站可以使用 JavaScript／Sites can use JavaScript**。
6. 看下面的禁止列表里，有没有把 Claude 或 Google 单独加进去。

如果登录、聊天都正常，这一项只查看即可，不需要重置全部浏览器设置或清空所有 Cookie。

## 9 检查 Google 账号安全

1. 打开 <https://myaccount.google.com/>。
2. 点击右上角 **头像**，确认是自己的目标账号。
3. 点击左侧 **安全性**。有些版本叫 **安全性与登录**。
4. 找到 **恢复邮箱／辅助邮箱**，确认是自己长期掌握的邮箱。
5. 找到 **恢复手机号／辅助手机号**，确认是自己掌握的号码。
6. 找到 **两步验证**，点击进入。
7. 如果没有开启，按照 Google 页面提示选择自己能长期使用的验证方式。
8. 把备用恢复方式保管好，不要把验证码写进这份文档或发给其他人。

如果不容易找到某一项，直接打开官方安全检查页：<https://myaccount.google.com/security-checkup>，逐项查看提示。

这一步保护 Google 账号，不是用来保证 Claude 不触发验证。

## 10 如果不想让 Claude 开机自动打开

### 关闭 Claude 主程序的启动项

1. 按 **Win + I**。
2. 点击 **应用**。
3. 点击 **启动**。
4. 在列表里找到 **Claude**。
5. 如果不希望它登录 Windows 后自动打开，把 Claude 右边的开关设为 **关**。

找不到时可以用另一种方法：

1. 按 **Ctrl + Shift + Esc** 打开任务管理器。
2. Windows 11 点击左边 **启动应用**；Windows 10 点击上方 **启动**。
3. 找到 Claude，查看状态。
4. 如果显示 **已启用**，右键点击它，选择 **禁用**。
5. 如果显示 **已禁用**，不用再改。

如果列表没有 Claude，就记录“没有列出”，继续检查下面一项。

### 关闭 Windows 恢复上次应用

1. 打开 **设置**。
2. 点击 **账户**。
3. 点击 **登录选项**。
4. 向下找到 **其他设置**。
5. 找到 **自动保存我可重启的应用，并在我重新登录时重启它们**，或意思相近的开关。
6. 如果不希望 Windows 恢复上次打开的程序，把它设为 **关**。

有的版本没有这个选项，找不到就跳过。这会影响其他支持恢复的应用，不只影响 Claude。需要恢复时，将刚才关掉的开关重新打开。

## 11 如果不想 Chrome 后台运行或恢复 Claude 网页

### 关闭 Chrome 的后台应用

1. 在 Chrome 点击 **右上角三个点 → 设置**。
2. 点击左边的 **系统／System**。
3. 找到 **关闭 Google Chrome 后继续运行后台应用**。
4. 如果你不需要这个功能，把开关设为 **关**。

如果左边找不到“系统”：

1. 点击 Chrome 设置页面上方的 **搜索框**。
2. 输入 **后台**；英文界面输入 **background**。
3. 在搜索结果里查看这个开关。

这个开关可能影响同一套 Chrome 的多个用户和扩展后台功能。需要恢复时重新打开；如果没有该选项，先跳过。

### 避免下次开 Chrome 又恢复 Claude 网页

1. 仍在 Chrome 设置中，点击左边 **启动时／On startup**。
2. 选择 **打开新标签页／Open the New Tab page**。
3. 不选 **继续浏览上次打开的网页／Continue where you left off**，如果你不希望它自动恢复先前的 Claude 标签。

这项只决定 Chrome 打开后显示什么网页，不等于 Windows 开机自启 Chrome。

## 12 查看 Cowork 后台服务 不需要修改

1. 按 **Win + R**。
2. 输入 `services.msc`。
3. 按 **回车**。
4. 在列表里找名称带 **Claude** 或 **Cowork** 的服务。
5. 双击打开。
6. 看上方 **服务名称**，确认是不是 `CoworkVMService`。
7. 记下 **启动类型**，例如“自动”。
8. 记下 **服务状态**，例如“正在运行”。
9. 点击 **取消**，关闭属性窗口。

**不要点击“停止”，也不要把启动类型改成“禁用”。** 此处只是检查，停用可能影响 Cowork 功能。

没有找到这个服务，可以记录“未找到”，不同安装版本可能不一样。服务正在运行，也不代表 Claude 账号正在联网。

## 13 退出后怎么检查 之后能不能换 IP

### 完全退出 Claude

1. 先保存正在做的内容，等正在执行的任务结束。
2. 看桌面右下角，点击 **显示隐藏的图标** 的向上箭头。
3. 如果有 Claude 图标，右键点击它。
4. 点击 **退出／Quit／Exit**。
5. 按 **Ctrl + Shift + Esc**。
6. 进入 **进程**，搜索或查找 **Claude**。
7. 看聊天主程序是否仍在运行，不要把 `cowork-svc.exe` 当作聊天窗口强行结束。

只点 Claude 窗口右上角的关闭按钮，不一定等于完全退出。

### 退出 Chrome

1. 保存其他 Chrome 窗口里正在做的事情。
2. 点击 Chrome 右上角 **三个点**。
3. 点击 **退出／Exit**。

这个动作可能关闭同一套 Chrome 的多个用户窗口。只想关一个窗口时可以点击右上角关闭，但那不能证明所有 Chrome 后台都已停止。

### 可选 查看当前有没有网络活动

这一项不会修改设置，不想查可以跳过。

1. 按 **Win + R**。
2. 输入 `resmon`，按回车。
3. 点击上方 **网络／Network**。
4. 在 **具有网络活动的进程** 中找 Claude 或 `cowork-svc.exe`。
5. 如果找到，勾选它。
6. 看下面的 **网络活动** 和 **TCP 连接**。

如果没有看到连接，只能记为“这次检查没观察到”，不能保证以后永远不联网。这里不用点击“结束进程”。

### 接下来可以换 IP 做其他事情吗

可以。没有相关客户端向 Claude 发请求时，单纯更换电脑网络，不会自动把新 IP 告诉 Claude。下次打开 Claude 连接时，它会看到当时的出口。其他浏览器窗口、Claude Code、编辑器插件和其他设备也要分别考虑。
