# Claude 一键工具

桌面上有两个图标，可直接双击，也可以拖到 Dock 使用。

- **一键关闭 Claude**：直接执行关闭，先尝试正常退出 Claude 桌面版，再结束残留进程，最后复查并显示结果。无需先打开检查工具。
- **检查 Claude 进程**：只检查。发现进程时显示数量、PID 和可执行文件路径，也可以从结果窗口点击“一键关闭”。

关闭按钮会中断正在进行的 Claude 对话、Claude Code 和它们启动的本地任务。准备离开电脑时，先保存需要保留的工作，再双击关闭图标。

## 识别范围

检查当前 macOS 用户的以下本地进程：

- `/Applications/Claude.app/Contents/` 和 `~/Applications/Claude.app/Contents/` 中的桌面主程序和辅助程序。
- `~/Library/Application Support/Claude/claude-code/` 中桌面版内置的 Claude Code。
- `~/.local/share/claude/versions/` 中的原生 Claude Code，以及可执行文件名恰好为 `claude` 的独立安装。
- 使用 Node/Bun 直接运行 `node_modules/@anthropic-ai/claude-code/cli.js` 的 Claude Code。
- 检查时可以追溯到上述进程的子任务，例如 MCP、shell 和脚本进程。

工具按可执行路径和实际脚本入口识别，不会因为笔记路径、浏览器参数或普通命令里出现“Claude”文字就将它们纳入。保留父级终端和编辑器。每次发送结束信号前检查 PID、用户及进程启动时间，避免误伤复用 PID 的其他进程。

结果表示复查时的进程状态。浏览器中的 Claude 网页、其他电脑或远程服务器上的任务不在范围内；已经脱离 Claude 且无法追溯来源的孤立子任务也可能无法识别。工具不会修改 Claude 配置、卸载软件或删除聊天记录，也不会阻止你之后重新打开 Claude。

## 文件位置

正式应用位于 `~/Applications/Claude一键工具/`，桌面的两个图标是指向它们的快捷入口。源码、构建脚本和测试保存在本说明所在的文件夹。应用由本机系统编译器构建，可直接运行，无需安装 Python 或其他运行环境。

如需移除，将桌面两个入口及 `~/Applications/Claude一键工具/` 移到废纸篓即可。

## 重新构建与验证

在本文件夹中运行：

```bash
bash build.sh
bash test.sh
bash install.sh
```

仅检查进程（JSON 输出，不执行关闭）：

```bash
./build/ClaudeControl --status
```

测试使用合成进程信息和测试程序创建的模拟进程，不调用完整关闭流程，不结束用户真实 Claude。
